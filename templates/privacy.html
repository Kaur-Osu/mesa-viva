TUS DATOS, CON CLARIDAD

Aviso de privacidad.

Esta es una aplicación académica local de Desarrollo Web Profesional, Unidad 3. Usa datos de prueba durante la demostración.

Qué guardamos y para qué

Guardamos tu nombre, correo, la contraseña transformada mediante un hash y tus recetas favoritas. Se usan para crear tu cuenta, iniciar sesión y mostrar tu recetario personal. No se solicita domicilio, información de pago ni datos sensibles.

Sesiones y servicios externos

Durante el registro se consulta el dominio de tu correo mediante DNS sobre HTTPS a Cloudflare (o Google como respaldo) para verificar que pueda recibir mensajes; esta comprobación no envía correos ni demuestra la propiedad del buzón. Usamos cookies de sesión y de protección CSRF, necesarias para autenticarte y proteger formularios. Al buscar recetas, el servidor envía el texto de búsqueda a TheMealDB por HTTPS; no envía tu nombre, correo ni contraseña. Las imágenes de las recetas se cargan desde TheMealDB, que recibe la información técnica habitual de la conexión. El video, si lo abres, te lleva a YouTube.

Acceso y conservación

La base SQLite permanece en el equipo donde se ejecuta el proyecto. Cada cuenta sólo puede consultar y modificar sus propios favoritos. No se venden los datos ni se usan para publicidad. Para consultar, corregir o eliminar datos de esta demostración, solicita al responsable que administra el proyecto local que gestione tu cuenta mediante el panel de administración de Django.

Antes de una publicación real

El responsable de un despliegue público debe completar su identidad y medios de contacto, definir plazos de conservación y procedimientos para solicitudes de datos, habilitar HTTPS y revisar el aviso conforme al uso real de la aplicación. Este aviso describe exclusivamente la demostración académica local.
